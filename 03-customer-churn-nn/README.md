Deep Learning project for customer churn prediction.

# Objective

Evaluate Artificial Neural Network architectures for tabular classification tasks using Keras.

Main goals:
- Build neural network pipelines
- Compare architectures
- Benchmark neural networks against XGBoost

## Evaluation
- ROC AUC metric

---

# Main Learnings

- XGBoost generally outperformed neural networks on tabular data.
- Neural architectures require careful tuning for structured datasets.
- Keras workflows for tabular data were explored and validated.

Areas for improvement:
- Exploratory Data Analysis was skipped.
- Feature engineering was limited.
- Code documentation could be improved.

Future direction:
- Apply neural networks to image or NLP datasets where deep learning architectures are typically more effective.
